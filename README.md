# RAIA — MARK 1

Marketing-automation suite of three independent agents, deployed together from
this monorepo. Each is a self-contained Express + TypeScript (tsx) web app with
its own login, LLM chat, and toolset.

| Agent | Folder | What it does | Render service | Runtime |
|-------|--------|--------------|----------------|---------|
| **S.C.R.I.B.E** | [`scribe/`](scribe) | Content automation (briefs, drafts, fact-check) | `raia-scribe` | Node |
| **S.A.G.E** | [`sage/`](sage) | Autonomous SEO (keywords, audits, ranking, reports) | `raia-sage` | Docker |
| **N.O.V.A** | [`nova/`](nova) | Business development (prospecting, outreach, meetings) | `raia-nova` | Docker |

## Deploy to Render (Blueprint)

1. Push this repo to GitHub (already wired to `RAIA--1`).
2. In Render: **New → Blueprint** and pick this repo. Render reads
   [`render.yaml`](render.yaml) and creates all three web services.
3. Render will prompt for the secrets marked `sync: false`. Set, per service:
   - `AUTH_USERNAME`, `AUTH_PASSWORD` — the demo login.
   - `LLM_API_KEY` — a Groq key (default provider/model is Groq
     `openai/gpt-oss-120b`; change `LLM_PROVIDER`/`LLM_MODEL` for OpenAI/Anthropic).
   - `raia-scribe`: `TAVILY_API_KEY` — for real search data.
   - `raia-sage` (optional): `SERP_API_KEY` if you switch `SERP_PROVIDER` to
     `serpapi` (recommended — the free browser SERP is often CAPTCHA'd on
     datacenter IPs).
   - `AUTH_SECRET` is auto-generated by Render.
4. Deploy. Each service gets its own URL; open `/login`.

> **Free plan note:** services sleep when idle; the first hit after idle wakes in
> ~30-60s. SAGE/NOVA use Chromium (memory-heavy) only when you trigger SERP/PDF
> features — chat, keywords, and audits work fine on free.

## Local development

Each app runs independently:

```bash
cd scribe   # or sage / nova
cp .env.example .env   # then fill in AUTH_* and LLM_API_KEY
npm install
npm run dev            # watch mode
```

Default local ports: SAGE `8787`, NOVA `8788`, SCRIBE `8789`.

## Environment variables

Secrets live only in each app's `.env` (git-ignored) or the Render dashboard —
never committed. See `*/.env.example` for the full list per app.
